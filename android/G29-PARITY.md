# Android / 网页行为、视觉与验收边界

## 当前 0.2.8 实现

网页依据为同仓库 `public/index.html`、`public/style.css`、`public/app.js` 与 `public/call.js`；Android 为单 Activity、自定义 Fragment/View、C++ Engine/JNI。原生布局保留系统导航、权限和文件选择器，不是 WebView，也不是逐像素网页复刻。

| 网页功能/视觉 | 原生对应 | 验收解释 |
|---|---|---|
| 当前网页移动端布局（`public/style.css`：77px topbar、消息区13/14/13/20px inset、文本行24px、composer 10px侧边距） | 0.2.7 原生 topbar/insets/文本行/输入区间距同步 | 共享网页现行浅绿/暖白色板，不采用 10/27 前的旧蓝白截图作为当前目标；房间标记现改用与网页相同的线描聊天气泡图标；本版其余尚未逐像素对齐，视觉仍须实际检查 |
| 昵称门、会话恢复、房号/口令加入与创建 | Keystore Cookie、原生门页、房间抽屉和表单 | 设备 UI 与服务行为必须分别记录；历史版本通过不计入本版 |
| WebSocket、历史、日期/连续消息分组、删除同步 | C++ 消息索引/协议、OkHttp、原生列表/气泡 | 在线真实服务/本地 Worker 与内存 fixture 不可混称 |
| 图片缩略图/全屏、表情、引用和长按菜单 | 原生图片/缩放、参考表情资产、引用草稿/复制/本人删除 | 浅绿暖白和深色对应网页色板；Android 抽屉不是网页桌面两栏 |
| 音频 controls/进度 | `MediaPlayer`、暂停/继续/重播、SeekBar、音频焦点 | 失去音频焦点或 Home 停止播放，不自动恢复；合成 PCM 不代表真实麦克风音质 |
| 文件下载、图片/视频/音频保存 | 服务端授权下载 + `ACTION_CREATE_DOCUMENT` | 保存前复制独立快照，系统选择器触发 onStop 不会删掉待保存的源；取消清理快照；限制 100 MB，净化文档名 |
| 内联/全屏视频 | `VideoView` 与系统控制器 | 先授权下载再本地播放；与网页流式/弱网行为不同，开始/结束状态不证明画质和所有编码兼容 |
| 成员、多人/定向通话、邀请/接听/拒绝 | 房间成员、原生通话面板、`NativeCallSession` | 实际按钮、信令、轨道、解码和设备质量是不同验收层；测试应明确是哪一层 |
| 通话权限与中断 | 房间/生命周期代际校验、音频焦点、onStop 释放轨道/连接 | 权限回调不应启动已离开的房间；后台/模拟器熄屏后结束采集，返回不自动采集；不强制听筒/扬声器/蓝牙路由 |
| 浅色/深色、手机窄屏、输入与表情边界 | Android 系统主题/Insets、自定义布局 | 使用模拟器截图核对颜色/内容/控件；物理键盘、不同 OEM 和全部屏幕尺寸另列未覆盖 |

### 0.2.8 集中验证入口

实现补齐后一次冻结，`android.yml` 构建 Debug、回环 QA 与测试包，lint、C++ sanitizer、JNI、实际 Activity/UI、系统 DocumentsUI 保存和字节对照、Android 文件/焦点/取消检查、本地真实 Worker/D1/R2/DO。`android-sfu.yml` 只手动触发，连接已授权 `blue-room-test`，两台隔离 API29 模拟器测量双向 RTP/解码；peer 使用真实 Activity 的 View 接听/加入、静音、摄像头开关，再执行系统 Home 验证清理和无自动重启。测试准备会话和房间成员关系，不把这些准备称作手点建房/输入口令验收。

本文件描述实现和可运行验收入口，不提前宣称本版通过。实际冻结提交、Actions 运行号、APK/源码、校验和、截图和结论以随包 `ACCEPTANCE-0.2.8-<commit>.md` 为准。旧的 0.2.5 `cc2810b` 成功记录仅是历史基线，不能代替本版结果。

### 必须保留的未覆盖边界

- 实体摄像头、麦克风质量和听筒/扬声器/蓝牙路由；模拟相机/麦克风、RTP 和解码帧不能证明这些。
- 无后台推送；后台及模拟器屏幕熄灭时结束本机实时媒体，不承诺后台响铃或持续通话；带真实安全锁的实体锁屏/OEM 行为仍需设备验证。
- 实体设备锁屏、系统来电、OEM 进程回收、权限永久拒绝、所有弱网/重连/编码组合，不是一次模拟器回归可穷尽的场景。
- 完整网页每个视觉/交互场景和逐像素相同没有证明；原生文件选择器、下载后播放、权限流程与网页有平台差别。
- 所有保存/生命周期测试仅在隔离 QA 包/CI 模拟器；不清除用户已安装应用及数据，不部署或改动生产环境。

此前版本的具体验收仍可从 Git 历史及已交付报告读取，保留其提交和时间范围，不作为本版通过证据。

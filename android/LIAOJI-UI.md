# 轻聊 Android · 聊记风格聊天界面

以提供的《聊记-安卓版-源码.zip》中聊天页 XML、色板和消息行设计为视觉参考。聊天主界面采用暖米色底、紧凑顶栏、双方 36dp 圆形头像、绿色发出气泡、白色描边接收气泡、居中提示和时间分隔；夜间改用等价的深色暖色板。原参考是归档阅读器，没有发送区，轻聊将现有发送栏改为暖色胶囊并保留附件、表情和录音，继续支持回复、删除、媒体和通话入口。

仅改动原生客户端的界面、展示逻辑和相应验收断言。未引入参考项目的数据库、聊天归档/导入、脚本、AAR、品牌或权限；未改 Worker、C++ 协议核心、会话、媒体传输或签名配置。

验收使用独立包名 `com.lyrnox.qingliao.qa` 和回环服务；真机、线上通话、正式签名包和发布不由此覆盖。
